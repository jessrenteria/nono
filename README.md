# nono

A nonogram / Picross TUI.

![demo](assets/demo.gif)

# Usage

`nono` is not packaged yet. You can build it from source by cloning this repo
and building it locally.

Clone repo.

```sh
git clone https://github.com/jessrenteria/nono.git
```

Install dependencies and build.

```sh
bun install && bun run build
```

Enjoy!

```sh
nono
```
